# 在线背单词系统需求文档

- 版本：v1.1（2026-08-02）
- 状态：需求整理稿（细则基本确认，部分待展开，见 §7）
- 说明：本项目共同维护，版本号随需求修订递增。

---

## 1. 项目概述

在线背单词平台：**系统抽取句子，给出汉语句子并播放英语语音，用户根据语音按顺序逐词拼写**，通过「听写句子 → 定位不会写的词 → 提示词/句入生词本」的机制，实现个性化单词记忆与复习。

## 2. 术语

| 术语 | 含义 |
|------|------|
| 练习单元 | 一次练习 = **一道题（一个句子）**，逐词拼写 |
| 光标词 | 当前按顺序待拼写的单词（位置由已输入词数决定） |
| 未测试句子 | 尚未参与过测试的句子（抽取池来源之一） |
| 已掌握单词 | 正确拼写过的单词（单词级状态） |
| 生词本 | 用户未掌握、由**「单词 + 其所在句子」**构成的集合 |
| 当日已测试句子 | 当天测试过的句子（右侧列表展示） |

## 3. 功能需求

### 3.1 核心练习流程

1. 用户进入系统后，**设定本次练习的句子数量**，点击**开始练习**，计时器开始计时。
2. 系统按比例从「**未测试句子 + 生词本句子**」中抽取句子作为本次练习的题目。
3. 每道题：系统给出**汉语句子**作为翻译提示，并**播放英语语音**。
4. 播放完成后，用户根据语音**按顺序、逐字符拼写**，**大小写需一致**：每个字符输入正确即校验通过、光标自动前进到下一个字符；单词全部字符输完自动进入下一个词；整句所有词输完该题完成；**正确拼写完的单词记录为「已掌握」**（统计展示用，见 §3.2）。
5. 无法拼出当前词时：
   - 点击**朗读**：重听**当前光标词**的发音；
   - 点击**提示词**：显示灰色完整单词，用户**再手动照敲一遍**后进入下一词；**该单词连同所在句子写入生词本**。
6. 词位切分：缩写按**完整单词**计 1 个空位（如 `don't`），撇号/连字符属单词内字符，由用户输入；句间标点与空格由系统预显，用户只输入单词内的字符。
7. 直到用户完成本次练习，**计时器停止**，系统**记录本次练习**（句子数量、用时、每个词的结果）。
8. 操作按钮：**朗读 | 提示词 | 报告句子有误**。
   - 朗读：朗读当前光标词（首次自动播放整句；逐词拼写时只重听当前词发音）。
   - 提示词：显示当前光标所在单词（灰色淡化），该**单词及其所在句子**加入生词本，用户照敲后进入下一词。
   - 报告句子有误：用户发现句子不完整/有 OCR 错误时上报，提交至系统待处理（见 §3.6）。

> 说明：无「拼错」与「放弃」概念——逐字符正确才前进；**入生词本的唯一途径：点击「提示词」**。

### 3.2 生词本

1. **生词本记录「单词 + 所在句子」**（word_id + sentence_id）。
   - 一个单词可能出现在多个句子，且不同句子下都被提示过 → 生词本中**同一单词可有多个条目（不同句子）**。
   - 一个句子含多个词 → 一个句子可产生多个生词本条目对应的词，但每个生词本条目仍是「词 + 句」对。
2. **入生词本的唯一途径**：点击「提示词」（该词及其所在句子同时写入）。
3. **移除机制**：生词本条目按「词句对」独立判定——该词在该句被抽到复习并**正确拼写一次，即移除该词句对**；同句内其他未掌握词句对、该词在其他句子的词句对，均不受影响。

### 3.3 测试抽取

1. 抽取对象为**句子**（非单词）——通过听写句子定位不会写的词。
2. 两个抽取池：
   - **未测试句子**：抽到并完成拼写即记为**已测试**，移出未测试池，不再重复抽取（广覆盖新词）。
   - **生词本句子**：用于**复习**，会被重复抽取，直到其「词+句」条目被一次正确拼写移除。
3. 两个池**按比例抽取**；抽取数量 = 用户设定的句子数量。
4. 具体比例值待定（建议可配置，见 §7）。

### 3.4 语音

1. **句子音频**：TTS 生成整句语音（拟定模型 mimo-v2.5-tts，见 §6）。采用**入库时离线预生成一次**：句子清洗入库即合成整句音频并落盘，`sentences` / `audio` 表记 `audio_url`，播放零等待（不采用「抽到才在线合成」）。
2. **单词音频**：**从句子音频中按词时间戳切片提取播放**，不单独生成单词音频（词在真实句中发音，连读/弱读准确）。
3. 语音表存「句子音频 + 每词起止偏移（start/end ms）」，播放当前词 = 播放句音频对应切片。
4. 词时间戳可在句子合成时同步生成（mimo 原生支持则用，无则 Whisper 对齐兜底，见 §7）。

### 3.5 练习计时与记录

1. 用户设定本次练习**句子数量**，点击开始练习，**计时器**开始计时。
2. 完成本次练习后计时停止，系统记录：练习句子数、实际用时、每个词的结果（**已掌握/加入生词本**）。
3. **会话与中断**：本次会话内句子不重复抽取；跨会话可重复（尤其生词本句）。练习中途离开/关闭页面：**保存已完成部分，未完成不计，下次从新会话开始**。

### 3.6 报告句子有误

1. 用户在使用中发现句子不完整、翻译有误或含 OCR 错误时，可点击「**报告句子有误**」上报。
2. 上报数据发至系统待处理队列；被报告多次或经处理的句子，后续抽取时优先规避。
3. 数据表：schema 见 §5（sentence_reports）。

## 4. 界面设计

### 4.1 主界面

```
     拼写区域                                           列表记录当日已测试的句子
+---------------------80%---------------------+---------20%---------+
```

- 左侧 80%：拼写区域（练习主体）。
- 右侧 20%：当日已测试的句子列表。

### 4.2 拼写区域布局

```
        爸爸，我正考虑今年去意大利学习艺术。
        ___, ___ ________ _____ __ _____ __ ______ ___ ____ ____.
        ------------------------计时器（本次练习：设定句子数量→开始计时→完成停止并记录用时）
        {朗读|提示词|报告句子有误}
```

- 英文句子全部单词留空（仅保留标点与空格），用户**按顺序逐词拼写**；已拼出的词按序填入，光标词高亮。
- 标点与空格由系统预显；词内字符（含 `'`/`-`）由用户输入，逐字符校验。
- 计时器：练习会话级（非每词倒计时），开始/停止/记录总用时。

## 5. 数据需求

基础表（用户列举 + 功能推导）：

| 表 | 说明 |
|----|------|
| 单词表 words | id、词形、词频、出现年份等（来源于词表素材） |
| 句子表 sentences | id、英语句子、汉语句子、真题来源标注 |
| 句子-单词关联 sentence_words | sentence_id、word_id（多对多） |
| 语音表 audio | id、sentence_id、句子音频文件、时长、**每词起止偏移 JSON（[{word, start_ms, end_ms}]）** |
| 用户表 users | id、账号、密码（登录）、昵称、偏好设置 |
| 用户生词本 user_vocab | **user_id、word_id、sentence_id**、加入时间（同一词不同句子可多条） |
| 单词状态 word_status | user_id、word_id、状态（已掌握/…）、更新时间（**仅展示统计，不参与抽取**） |
| 练习会话 practice_sessions | id、user_id、设定句子数、开始时间、结束时间、实际完成句子数、总用时 |
| 测试记录 test_records | id、session_id、user_id、word_id、sentence_id、时间、结果（已掌握/加入生词本） |
| 句子报告 sentence_reports | id、sentence_id、user_id、时间、状态（待处理/已处理） |

> 素材来源：`res/study_sentences.md`（真题句子 + correct 词标记，按词索引）。**抽取对象为句子**，故素材需从「按词组织」反解为「去重句子 + 句子-词关联」；入库前**清洗 OCR 噪声、去重**，优先 correct 句、不足用正文句。**汉语句子由英文例句机器翻译生成**。

## 6. 非功能需求

- **数据库**：SQLite。
- **TTS**：拟用 **mimo-v2.5-tts**（单端生成，女生音色）；**入库时离线预生成整句音频**，单词发音 = 句子音频按词时间戳切片提取。
- 待定：前端技术栈、后端框架、部署形态、汉译是否人工校对等（见 §7）。

## 7. 待确认问题清单

**已确认（v0.1–v1.0）**：
- 练习模式：整句输入、全部单词留空，**按顺序逐字符拼写（大小写需一致）**；逐字正确自动前进；正确拼写的词记「已掌握」。
- 词位：缩写按完整词（`don't`=1 空位，`'` 由用户输入）；句间标点/空格系统预显。
- 抽取对象为**句子**；单词是「句子→生词本」的桥梁；入生词本唯一途径 = 点击「提示词」。
- 生词本条目 = **「单词 + 所在句子」**（word_id+sentence_id），一词多句可各入本。
- 无「拼错」「放弃」；生词本按**词句对**独立移除：一次正确拼写即移除该条，同句他句其余词句对不受影响。
- 朗读 = 当前光标词发音；语音 = 句子音频按词时间戳切片提取。
- **语音合成 = 入库时离线预生成一次**（整句音频 + 词时间戳），播放零等待；单词发音 = 句音频对应切片。
- 未测句子测完归档移出、生词本句子复习重复抽；会话内不重复、跨会话可重复。
- 移除倒计时/超时，改**练习会话计时器**；中途离开保存已完成部分、未完成不计，下次新会话。
- 提示词：显示灰色完整词，用户**再手动照敲一遍**后进入下一词。
- 新增**「报告句子有误」**：用户界面可上报残缺/OCR 错误句子。
- 需**账号注册、登录、多用户数据隔离**。
- 右侧列表：句子 + 用时，可点开重听（非进行中）。
- 配置项：抽取比例、每轮测试数量、语音开/关（默认开，关后无语音提示）。
- 汉语句子由英文例句（清洗后）机器翻译生成。

**待确认**：

1. **测试抽取比例**：未测句子 : 生词本句子 = ？（建议默认如 7:3，可配置）
2. **句子池的可持续性**：大部分未测句子测完、生词本也不多时，池耗尽怎么处理？
3. **汉译质量**：是否需人工抽查校对？（建议：抽查校对）
4. **词时间戳获取方式**：mimo-v2.5-tts 原生如不支持词边界，用 Whisper 对齐兜底？（技术见 §3.4）
5. **前端 / 后端框架 / 部署形态**（单机自用 / 局域网 / 公网在线）。
