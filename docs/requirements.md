# 在线背单词系统需求文档

- 版本：v1.9（2026-08-06）
- 状态：需求定稿（v1.9）
- 说明：本项目共同维护，版本号随需求修订递增。

---

## 1. 项目概述

在线背单词平台：**系统抽取句子，给出汉语句子并播放英语语音，用户根据语音按顺序逐词拼写**，通过「听写句子 → 定位不会写的词 → 提示词（连带所在句子）入生词本」的机制，构建**学习（听写定位生词）→ 复习（按记忆曲线巩固）→ 测试（科学判定掌握）**三环节闭环的个性化单词记忆体系。

## 2. 术语

| 术语 | 含义 |
|------|------|
| 练习单元 | 一次练习 = **一道题（一个句子）**，逐词拼写 |
| 光标词 | 当前按顺序待拼写的单词（位置由已输入词数决定） |
| 未测试句子 | 尚未参与过测试的句子（抽取池来源之一） |
| 已掌握单词 | **经间隔递增连续成功达掌握阈值**判定的单词（见 §3.2.3；word_status 仅统计展示、与生词本移除逻辑独立、不参与抽取） |
| 生词本 | 用户未掌握、由**「单词 + 其所在句子」**构成的集合 |
| 到期复习队列 | 词句对按 `next_review`（下次复习日期）排序的队列，到期（≤ 今日）者优先抽取复习 |
| 掌握阈值 | 词句对「标记已掌握」所需的连续成功次数（默认 5 次，见 §7） |
| 降级 | 已掌握词句对经测试失败后状态回退：标记未掌握、间隔重置、错误频次 +1，重新进入复习队列 |
| 错误频次 | 词句对历史拼写失败次数（用于测试池加权） |
| 测试（验收） | 第三模式：对生词本词句对进行**禁提示**的验收式听写，通过判定掌握、失败降级（见 §3.3） |
| 当日已测试句子 | 当天测试过的句子（右侧列表展示） |

## 3. 功能需求

### 3.1 核心练习流程

1. 用户进入系统后，**设定本次练习的句子数量**，点击**开始练习**，计时器开始计时。
2. 系统按**模式**从对应抽取池抽取句子（练习=未测试句、复习=到期复习队列、测试=测试内容池，见 §3.3）。
3. 每道题：系统给出**汉语句子**作为翻译提示，并**播放英语语音**。
4. 播放完成后，用户根据语音**按顺序、逐字符拼写**，**大小写需一致**：每个字符输入正确即校验通过、光标自动前进到下一个字符；单词全部字符输完自动进入下一个词；整句所有词输完该题完成；**正确拼写完的单词记录为「已掌握」**（统计展示用，见 §3.2）。
5. 无法拼出当前词时：
   - 点击**朗读**：重听**整句**发音；
   - 点击**提示词**：显示灰色完整单词，用户**再手动照敲一遍**后进入下一词；**该单词连同所在句子写入生词本**。
6. 词位切分：缩写按**完整单词**计 1 个空位（如 `don't`），撇号/连字符属单词内字符，由用户输入；句间标点与空格由系统预显，用户只输入单词内的字符。
7. 直到用户完成本次练习，**计时器停止**，系统**记录本次练习**（句子数量、用时、每个词的结果）。
8. 操作按钮：**朗读 | 提示词 | 报告句子有误**（练习/复习模式）；**测试模式仅「朗读 | 报告句子有误」——禁用提示词**（验收性质，见 §3.3）。
   - 朗读：重听**整句**发音（首次自动播放整句；重听默认播整句）。
   - 提示词：显示当前光标所在单词（灰色淡化），该**单词及其所在句子**加入生词本，用户照敲后进入下一词（练习/复习模式可用）。
   - 报告句子有误：用户发现句子不完整/有 OCR 错误时上报，提交至系统待处理（见 §3.6）。

> 说明：无「拼错」与「放弃」概念——逐字符正确才前进；**入生词本的唯一途径：点击「提示词」**（已掌握词经测试失败而降级回退的路径除外，见 §3.2.5）；**测试模式禁用提示词**（§3.3）。

### 3.1.5 内容分级体系（T047）

- **分级标准**：新概念英语 1-4 册大致对应 小学 / 初中 / 高中 / 大学 四阶段，作为难度分级基准。
- **词级别**（words.level）：1~4 = 新概念对应册级；5 = 编外篇（未收录在 1-4 册的词）。
- **句子级别**（sentences.level）：**派生**——由句中所有词的最高级别决定（如句子含 4 级词 → 4 级句），
  导入/词条变更时自动重算落库，保证「先分级词汇、句子自动分级」的一致性。
- **词条结构**：词义（words.meaning）、音标（words.phonetic）；后续扩展同义词/反义词关联（word_relations）。
- **句子多出处**：source 字段支持多值（如真题年份 + 新概念课文位置）。
- **版权策略**：echoo 为**个人自用**场景，直接使用新概念课文句子（个人学习合理使用）；
  若未来公开/商业分发，需替换为自编句子或取得授权。
- **数据现状**（T047-T052）：词表 7886 词（1 级 1524 / 2 级 1655 / 3 级 2459 / 4 级 1839 / 编外 409，
  含音标与词义 97% 填充、词发音音频 2692 词）；句库 5525 句（真题 1405 + 新概念课文 4124，分册语速句音频 100%）；
  词音频端点 `GET /api/audio/word/:word`。

## 3.2 生词本

1. **生词本记录「单词 + 所在句子」**（word_id + sentence_id）。
   - 一个单词可能出现在多个句子，且不同句子下都被提示过 → 生词本中**同一单词可有多个条目（不同句子）**。
   - 一个句子含多个词 → 一个句子可产生多个生词本条目对应的词，但每个生词本条目仍是「词 + 句」对。
2. **入生词本的唯一途径**：点击「提示词」（该词及其所在句子同时写入）。
3. **掌握判定与移除机制**（v1.9 起）：词句对**不再「一次拼对即移除」**，而是按**间隔递增复习**判定——每次拼写正确 → 间隔按序列前进（默认 1→3→7→16→35 天，见 §7）且连续成功次数 +1；**连续成功达掌握阈值（默认 5 次，且每次均为到期复习成功）→ 进入「待测试」状态（candidate）**：自动加入测试列表，**测试模式拼对通过后才标记已掌握**并移出复习/测试队列（仅统计展示）；测试失败则降级重新积累。未到期（提前/同日重复）复习成功**不推进间隔**（SM 时间语义，仅巩固）。任一次拼写失败或提示 → **间隔重置回 1 天、连续成功清零**（不踢出生词本）。该词在其他句子的词句对独立判定，互不影响。
4. **同句重复词**（如 "I I"）：词句对按 word_id + sentence_id 判定，**不区分句中位置**，同一句同一词仅一个词句对条目。
5. **降级路径**：已掌握词句对参与测试池复测（§3.3），复测失败 → 状态回退为学习中（mastered=false、间隔重置、错误频次 +1），重新进入复习队列——此路径不依赖「提示词」（测试模式禁提示）。

### 3.3 测试抽取

1. 抽取对象为**句子**（非单词）——通过听写句子定位不会写的词。
2. 抽取池：
   - **未测试句子**：抽到并完成拼写即记为**已测试**，移出未测试池，不再重复抽取（广覆盖新词）。
   - **生词本句子**：用于**复习**，按**到期队列**（next_review ≤ 今日）优先重复抽取，直到该句词句对全部达掌握阈值移出（§3.2.3）。
   - **测试内容池**：用于**测试**（验收），由临近掌握词句对、高错词、已掌握词句对构成（见下）。
3. 三种模式，按模式从对应池抽取：
   - **练习模式**：只从**未测试句子**池抽取（学新内容，定位生词）。
   - **复习模式**：只从**生词本句子**池抽取，**到期优先**（next_review ≤ 今日的词句对所在句子先抽，不足再随机补）；**针对词**——句子整句呈现（生词高亮）、仅默写生词本中的词（已掌握词自动跳过，人名同样跳过），各词句对独立推进间隔。
   - **测试模式**（验收）：内容池 = ①**临近掌握**（连续成功 ≥ 阈值−2 且未掌握）优先；②**错误频次高**（历史失败 ≥ 2 次）加权；③**已掌握词句对**低频复测（防遗忘回潮）。**全程禁用提示词**（前端隐藏、后端拒绝）；candidate（待测试）词句对**最高优先级**入测试池；拼对 → 推进间隔，candidate 验收通过 → 标记已掌握；拼不出 → 降级（间隔重置 + 错误频次 +1，§3.2.5）。
4. 每次抽取数量 = 用户设定的句子数量（默认10句）；测试模式开始前可选择范围（全部生词本 / 仅临近掌握 / 高错词 / 已掌握复测）。
5. **池耗尽兜底**：当对应池不足设定数量时，从**已测试句子**中抽取补齐（不再出现无题可练）。

### 3.1.4 中文提示分阶段策略（T043）

| 模式 | 拼写中 | 提示/完成后 |
|------|--------|------------|
| 练习 | 隐藏汉译（练听力、暴露生词） | 整句拼写完成后显示汉译（建立母语锚点） |
| 复习 | 隐藏汉译 | 第一次点提示 → 只显示汉译（语义锚点，不入本、不算失败）；第二次点提示 → 显示单词（入本+重置） |
| 测试 | 隐藏汉译 | 禁止一切提示（含汉译，§3.3） |

判定：复习模式一级提示（看汉译）后拼出单词 → 算成功（有效回忆推进间隔）；二级提示（看单词答案）后拼出 → 算失败（重置）。
## 3.4 语音

1. **句子音频**：TTS 生成整句语音（拟定模型 mimo-v2.5-tts，见 §6）。采用**入库时离线预生成一次**：句子清洗入库即合成整句音频并落盘，`sentences` / `audio` 表记 `audio_url`，播放零等待（不采用「抽到才在线合成」）。
2. **当前版本仅整句朗读**：重听即重播整句音频（首次自动播放、点击「朗读」重听）。
3. ~~词级音频切片（单词发音=句子音频按词时间戳切片提取、每词起止偏移、Whisper 对齐兜底）~~：**已移入创意池，后续版本再评估**（v1.7，T015）。词级切片的考量：单拼一词时重听整句更符合「听写句子定位生词」的设计初衷（词在真实句中发音，连读/弱读准确、上下文有助于回忆）；且 Whisper 词级对齐实现成本较高，当前版本收益不足。**注（v1.9）**：复习/测试模式**针对词**需定位单个生词发音，词级切片为其配套需求，优先级随三环节闭环上升，仍列入后续版本评估。

### 3.5 练习计时与记录

1. 用户设定本次练习**句子数量**，点击开始练习，**计时器**开始计时。
2. 完成本次练习后计时停止，系统记录：练习句子数、实际用时、每个词的结果（**已掌握/加入生词本/测试通过/测试失败**）；**测试模式额外记录得分**（拼对词数 / 测试词数，见 §4.3）。
3. **会话与中断**：本次会话内句子不重复抽取；跨会话可重复（尤其生词本句）。练习中途离开/关闭页面：**已完成句子视为「已测试」并移出未测池，其已掌握/生词本变更同步落库；未完成不计，下次从新会话开始**。

### 3.6 报告句子有误

1. 用户在使用中发现句子不完整、翻译有误或含 OCR 错误时，可点击「**报告句子有误**」上报，**弹出输入框可附具体错误描述**（如「一句音频播放了两个句子」，描述可选、留空也可提交）。
2. 上报数据（句子 + 描述）发至系统待处理队列；被报告多次或经处理的句子，后续抽取时优先规避。
3. 数据表：schema 见 §5（sentence_reports）。

### 3.7 用户与数据隔离

1. 使用前需**注册 / 登录**（账号 + 密码，密码哈希存储，见 §5 users）。
2. 各用户的**已测试句子、生词本、练习记录、已掌握统计**均相互隔离。

### 3.8 用户等级体系（T053）

- **等级含义**：用户等级 1~4 = 可学内容级别（对应 小学/初中/高中/大学 四阶段，users.level 默认 1）。
- **内容抽取规则**：
  - 等级 1：练习**纯 1 级**内容；
  - 等级 ≥2：**混合 1:1**（上一级未测试句 + 本级句各半），上一级未测试句抽完转纯本级；
  - 上一级**已测试句**不重复作为新句抽取（抽完即转纯）；兜底不跨级（用户只练已解锁级别）；
  - 无级别句（通用内容）所有等级可练。
- **升级测试（邀请制）**：
  - **触发**：连续 3 轮练习**句子正确率 ≥80%**（句子正确 = 句内所有词无提示拼对）；
  - **抽词三级规则**：① 当前级未练习过的词（扩大受测面）→ ② 全练过后抽未掌握词 → ③ 全掌握自动解锁下一级并抽下一级词；
  - **测试形式**：无提示 + **句时限 = 词数 × 5s × 150%**（超时整句算错）+ 20 句；
  - **通过**：句子正确率 ≥60% → 解锁下一级（users.level+1，写 levelup_history）+ 升级大特效；失败可重测。
- **勋章**：I/II/III/IV 级（按用户等级点亮，金色勋章卡）。
- **设置页**：基本信息（用户名/昵称/等级/生词本/掌握数）+ **足迹**（过去 7 天 练习/复习/测试/升级 操作记录）+ 勋章展示。
- **主界面**：新增「🏅 升级」卡片（有活跃邀请可进测试，否则提示当前等级与规则）。

## 4. 交互要点

（视觉/布局为实现细节，见前端代码；此处仅记录交互规则）

### 4.1 主界面

- **首页入口卡片**：练习 / 复习 / 测试 / **升级（🏅，T053）**；顶栏含「⚙️ 设置」入口（T053c）。
- **当日已测试句子列表**：句子 + 用时，可点开重听（练习进行中不可重听）。
- **登录引导（强引导不强制）**：登录后默认进入「今日到期复习」队列（到期词按 next_review 排序，一键开始；可跳过进入其他模式）；首页显示**到期横幅**「有 N 个到期词待复习」（可配置为强制进入复习，见 §7）。

### 4.2 拼写交互

- **长句适配（T051）**：不拆句，句子越长字号越小（≤15 词 28px → ≤25 词 24px → ≤35 词 21px → >35 词 19px）、
  行高压缩（2→1.5）、容器 max-height 78vh 滚动兜底。
- **词音频（T052）**：练习/复习中点击句子中的单词可播放该词发音（测试模式禁用，防提示）。


```
        爸爸，我正考虑今年去意大利学习艺术。
        ___, ___ ________ _____ __ _____ __ ______ ___ ____ ____.
        ------------------------计时器（本次练习：设定句子数量→开始计时→完成停止并记录用时）
        {朗读|提示词|报告句子有误}
```

- 英文句子全部单词留空（仅保留标点与空格），用户**按顺序逐词拼写**；已拼出的词按序填入，光标词高亮。
- 标点与空格由系统预显；词内字符（含 `'`/`-`）由用户输入，逐字符校验。
- 计时器：练习会话级（非每词倒计时），开始/停止/记录总用时。
- 朗读按钮重听整句发音。
- 操作按钮：练习/复习模式为「朗读 | 提示词 | 报告句子有误」；**测试模式为「朗读 | 报告句子有误」（无提示词）**。

### 4.3 测试结果页（测试模式完成时展示）

- **得分**：拼对词数 / 测试词数（正确率）。
- **用时**、**本次测试范围**（全部/临近掌握/高错词/已掌握复测）。
- **错词列表**：本次拼不出的词句对（一键标记「需强化」→ 自动进复习队列）。
- 提供「继续复习」与「返回首页」入口。

## 5. 数据需求

基础表（用户列举 + 功能推导）：

| 表 | 说明 |
|----|------|
| 单词表 words | id、词形、词频、出现年份等（来源于词表素材） |
| 句子表 sentences | id、英语句子、汉语句子、真题来源标注 |
| 句子-单词关联 sentence_words | sentence_id、word_id（多对多） |
| 语音表 audio | id、sentence_id、句子音频文件、时长、每词起止偏移 JSON（预留字段 `word_offsets`，当前版本未用，创意池实现时启用） |
| 用户表 users | id、账号、密码（哈希存储）、昵称、偏好设置 |
| 用户生词本 user_vocab | **user_id、word_id、sentence_id**、加入时间、**interval（当前间隔天数）、review_count（连续成功次数）、next_review（下次复习日期）、status（学习中/已掌握）**（同一词不同句子可多条） |
| 单词状态 word_status | user_id、word_id、状态（已掌握/…）、更新时间（**仅展示统计，不参与抽取**；掌握判定以词句对为准，见 §3.2.3） |
| 练习会话 practice_sessions | id、user_id、**mode（practice/review/test）**、设定句子数、开始时间、结束时间、实际完成句子数、总用时 |
| 测试记录 test_records | id、session_id、user_id、word_id、sentence_id、时间、结果（已掌握/加入生词本/**测试通过/测试失败**） |
| 句子报告 sentence_reports | id、sentence_id、user_id、时间、状态（待处理/已处理）、**错误描述 description（可选，用户输入）** |

> 素材来源：`res/study_sentences.md`（真题句子 + correct 词标记，按词索引）。**抽取对象为句子**，故素材需从「按词组织」反解为「去重句子 + 句子-词关联」；入库前**清洗 OCR 噪声、去重**，优先 correct 句、不足用正文句。
>
> 汉译分工：**由翻译人员人工提供**（非机器翻译），**无需额外人工抽查**。**入库前必须校验：每个句子均有完整汉译、不留空**；句子不完整（残缺/OCR 噪声）的按 §3.6 处理，不上线。

## 6. 非功能需求

- **数据库**：SQLite。
- **TTS**：拟用 **mimo-v2.5-tts**（单端生成，女生音色）；**入库时离线预生成整句音频**，播放/重听均为整句（词级切片见创意池）。
- **部署形态**：局域网使用。前端 Vue + 主后端 TypeScript（Node） + 独立 Python TTS 服务。

## 7. 配置项

所有用户可配置参数（存储于 users.preferences），默认值如下：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 模式抽句规则 | 练习=只取未测试句，复习=到期优先生词本句，测试=测试内容池 | 三种模式从对应池抽取（见 §3.3） |
| 每轮练习句子数量 | 每次练习前由用户设定 | 开始练习前设定，记录于 practice_sessions（见 §3.5） |
| 语音开关 | 开 | 关闭后无语音提示，仅显示汉译（见 §3.1） |
| 掌握阈值 | 5 次连续成功 | 词句对标记已掌握所需连续成功次数（见 §3.2.3） |
| 复习间隔序列 | 1→3→7→16→35 天 | 每次拼对推进一档；失败/提示重置回 1 天（见 §3.2.3） |
| 登录引导 | 强引导（默认进入到期复习，可跳过） | 可配置为「强制进入复习」（见 §4.1） |
